MCP Operation Notes
====================

This document describes installing and operating the MCP model-management and dashboard features.

Install model management (one-shot):

```bash
# from repo root
sudo bash scripts/install_model_service.sh
```

This installs `/usr/local/bin/manage_models.py`, creates `/var/lib/mcp-llms`, installs tmpfiles and systemd units, and enables `mcp-model-cleanup.timer`.

Download a model and index it (example):

```bash
sudo bash scripts/download_model.sh --url https://example.com/ggml-coder.bin \
  --checksum sha256:<HEX> --dest /var/lib/mcp-llms/ggml-coder.bin

# inspect index
python3 scripts/manage_models.py --index /var/lib/mcp-llms/models.json list
```

Health and readiness:
- Dashboard exposes `/health` and `/health/ready` for liveness/readiness.
- Metrics are available at `/metrics` (Prometheus format).

Systemd hardening:
- Services created under `packaging/systemd/` include conservative sandboxing options such as `ProtectSystem=full`, `PrivateTmp=yes`, and `NoNewPrivileges=yes`. If you customize service user/home paths, add explicit `ReadWritePaths` entries.

CI:
- A minimal GitHub Actions workflow `.github/workflows/ci.yml` runs linters and an EE smoke test on push/pull_request to `main`.

Ansible:
- Use `ansible/playbooks/install_mcp_services.yml` to install components across targets (idempotent, uses `package` and `copy` modules).

If you want, I can:
- Add monitoring alerts and Grafana dashboards for the `/metrics` data.
- Create a system user `mcp-ai` and package installation playbook to fully configure service users and file permissions.

Prometheus/Grafana (quickstart):

You can run a local Prometheus + Grafana stack using the provided docker-compose under `monitoring/`:

```bash
cd monitoring
docker compose up -d
# Prometheus UI: http://localhost:9090
# Grafana UI: http://localhost:3000 (admin/admin)
```

Create PRs from LLM-suggested patches:

Use `scripts/create_pr_from_patch.sh` to create a branch from a patch file and open a PR (requires git remote and optional `gh` CLI):

```bash
scripts/create_pr_from_patch.sh --repo . --patch ./.hal_suggestions/patches/patch1.diff --create-pr --title "LLM suggestion: fix foo" --body "Suggestion generated by MCP"
```
